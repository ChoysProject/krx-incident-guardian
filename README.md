# KRX 장애예방 가디언 (KRX Incident Guardian)

> AX 인재전쟁 해커톤 — 대상 기업 : 카카오페이증권 | 주제 : KRX 외부연계 장애 예방 및 대응

카카오페이증권은 주문 체결·정산·시세 수신 등 핵심 업무 전반에서 KRX 외부연계를 필수적으로 사용합니다.
외부연계 오류는 금융 서비스 신뢰도 저하와 반복적인 업무 타격으로 직결되는 고위험 영역입니다.

본 플러그인은 금융권 외부연계 장애에 대응하는 **3단계 구조**로 설계되었습니다.

| 단계 | 목적 | 내용 |
|------|------|------|
| 1단계 | 사전 감지 | 장애 징조를 조기에 탐지하여 선제 대응 |
| 2단계 | 신속 대응 | 장애 발생 시 상황을 즉시 공유하고 대응 절차 실행 |
| 3단계 | 재발 방지 | 장애 원인을 분석하고 재발 방지 조치 수행 |

---

## 평가 질문지

1. 무엇을, 누가, 어떤 상황에서 쓰나요?

**무엇을**
KRX 거래 로그를 배치 방식으로 지속 모니터링하며, 세 가지 핵심 기능을 제공합니다.
- **사전 감지** : KRX API 응답 시간이 일시적·지속적으로 증가할 경우 장애 징조를 조기 탐지합니다.
- **신속 대응** : 실제 장애 발생 시 담당자에게 즉시 상황을 공유하고, AI를 통해 에러 세부 내용과 대응 절차를 전달합니다.
- **재발 방지** : 장애 내용을 장애관리 리스트에 저장하고 분석 결과를 별도 관리하여 동일 장애의 재발을 방지합니다.

**누가**
카카오페이증권의 대외연계 운영자, 연계 시스템 개발자, 연계 관련 업무 담당자가 사용합니다.

**어떤 상황에서**
KRX 응답 지연 등 이상 징조가 감지될 때, 또는 실제 장애가 발생했을 때 플러그인이 로드된 AI를 통해 담당자에게 자동으로 상황이 전달됩니다.


2. 왜 이 문제를 선택했나요?

최근 카카오페이증권·토스증권 등 인터넷 금융사에서 대외연계 이슈로 인한 장애가 줄어들지 않고 오히려 증가하는 추세입니다.
장애를 얼마나 빠르게 조치하느냐보다, 초기 징조를 사전에 파악하고 선제적으로 대응하는 것이 핵심이라고 판단했습니다.

또한 실무 경험상 외부연계 이슈 하나가 사내 금전적 손실과 함께 고객 신뢰도를 크게 훼손하는 사례를 직접 목격했습니다.
금융사에서 고객 신뢰도는 가장 최우선으로 지켜야 할 가치이기 때문에, 이를 보호하기 위한 실질적인 수단으로 본 주제를 선택했습니다.

3. 플러그인은 어떻게 작동하나요?

Python 배치 스크립트(`monitor.py`)가 샘플 로그 디렉토리의 KRX 거래 로그를 주기적으로 읽으며 응답 시간과 에러 여부를 판단합니다.
이상이 감지되면 배치가 Codex CLI를 자동 호출하면서 해당 로그 내용을 함께 전달하고, AI는 `SKILL.md`에 정의된 지침을 바탕으로 단계를 판단하여 분석 결과를 출력합니다.

**시나리오별 로그 구성**

| 로그 파일 | 상황 | 플러그인 동작 |
|-----------|------|--------------|
| `normal.log` | 정상 응답 | 감지 없음, 대기 유지 |
| `stage1_slow.log` | 응답 시간 임계값 초과 | 1단계 발동 — AI가 지연 패턴 분석 후 사전 경고 출력 |
| `stage2_incident.log` | 에러 코드 발생 / 연결 차단 | 2단계 발동 — AI가 에러 원인 분석 + 담당자 대응 절차 안내 |

**3단계는 2단계 발생 시 자동으로 연결**
- 장애 내용을 정형화된 포맷으로 장애리 리스트(`incident_list.md`)에 자동 저장
- 발생 원인·조치 내역·재발 방지 항목이 포함된 분석 리포트를 별도 파일로 생성

4. AI를 어떻게 활용했나요?

대외연계에서 처리되는 로그는 초당 수십~수백 건 이상의 트래픽이 발생하는 환경으로, 
사람이 직접 읽고 판단하기에는 한계가 있습니다.

이에 AI를 다음 세 가지 역할로 활용했습니다.

- **사전 감지** : 배치 스크립트가 수집한 로그를 AI가 분석하여 장애 발생 조짐을 조기에 탐지하고 선제 조치를 안내합니다.
- **원인 분석 및 대응 안내** : 실제 장애 발생 시 어느 구간에서 에러가 발생했는지 AI가 세부적으로 분석하고, 담당자가 즉시 대응할 수 있도록 절차를 제시합니다.
- **장애 관리 및 재발 방지** : 동일한 에러가 반복되지 않도록 AI가 장애 내용을 정형화하여 장애관리 리스트에 기록하고 분석 리포트를 작성합니다.
